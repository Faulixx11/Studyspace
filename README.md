# STUDIO 01 — Fashion Storefront

Clean, responsive concept website for a contemporary fashion label.

## Preview
Open `index.html` in a browser, or deploy the `fashion-brand` branch with GitHub Pages.

## Included
- Responsive editorial homepage
- Collection section with category filters
- Product cards and add-to-bag interactions
- Slide-in bag drawer with quantity controls
- Cart persistence in localStorage
- Mobile navigation
- Newsletter form demo
- Story, brand values and footer sections

## Before launch
This is a front-end concept, not a production-ready online shop.

1. Replace **STUDIO 01** with the final brand name and logo.
2. Replace the sample product names, descriptions, prices and photos with real product information.
3. The product photos currently load from Unsplash as temporary visual placeholders. Use images you own or have permission to use before publishing.
4. Connect a real checkout/payment provider and order-management backend.
5. Connect the newsletter form to an email marketing provider.
6. Add real contact details, shipping/returns information, legal notice, privacy policy, terms and any other legally required information for the market where the shop operates.
7. Check product claims, sizing, availability, tax and shipping details before accepting orders.

## Main files
- `index.html` — page structure and product copy
- `styles.css` — layout, typography and responsive styling
- `script.js` — filters, mobile menu and demo cart
- `favicon.svg` — simple text-based icon

## GitHub Pages
In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select branch **fashion-brand** and folder **/(root)**, then save.
