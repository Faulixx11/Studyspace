# STUDIO 01 — Fashion Storefront\n\nResponsive fashion shop concept.\n\n## Features\n- Clean editorial landing page, brand story, FAQ\n- Product category filters, sorting and search\n- Product quick view with sizes, colors and demo size guide\n- Wishlist and variant-aware demo cart, saved locally\n- Free-shipping progress and subtotal\n- Simulated checkout (does not send, store, or process personal information/payments)\n- Cookie-choice banner; no analytics or advertising trackers\n- Responsive mobile navigation\n\n## Before publishing\nEverything is placeholder content: brand, product info, prices, sizes, images, shipping, contact/legal texts, socials. Replace photos with images you own or license. This is not a production store and has no payment, order, inventory, or newsletter backend. For an actual launch, involve a parent/guardian and have the relevant legal, privacy, tax, and business requirements reviewed.\n
